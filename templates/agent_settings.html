How to Customise the Agent
1. Open the instructions file

Edit modules/agent_instructions.py in your project directory. Each section is a clearly labelled Python string constant.

2. Modify any section

Change AGENT_PERSONA, TONE_GUIDELINES, SAFETY_RULES, EXPERTISE_DOMAINS, or any other constant. No other files need to be changed.

3. Restart the server

Run python app.py (or restart Gunicorn). The new instructions take effect immediately for all new conversations.

What you can customise
  • Agent name and persona / backstory
  • Expertise domains and depth of knowledge
  • Communication tone (formal / friendly / regional)
  • Response length and formatting style
  • Regional focus (state-specific advice)
  • Safety rules and restricted topics
  • Multi-farm and family support behaviour
Model settings (in .env)
  • WATSONX_MODEL_ID — switch Granite model variant
  • MAX_TOKENS — control response length (default: 1024)
  • TEMPERATURE — creativity level (0.0–1.0, default: 0.7)
  • WATSONX_URL — region endpoint
  • FLASK_DEBUG — development / production mode
